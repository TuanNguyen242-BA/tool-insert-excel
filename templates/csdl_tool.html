Tool tạo DQC/STD từ tài liệu thiết kế CSDL

Upload tài liệu, cấu hình điều kiện DQC/STD, kiểm tra kết quả và tải file Excel.

Chọn module

Bước 1: Upload tài liệu

Có thể upload nhiều file DOCX. Tool hỗ trợ format A/B như core bạn cung cấp.

Dùng cho chế độ merge hoặc diff ở bước 4.

Cách cấu hình: Chọn rule đang sử dụng, chọn loại dữ liệu và nhập điều kiện text theo từng phạm vi tìm kiếm. Dùng tab DQC hoặc STD để chỉnh riêng từng nhóm; chạy phân tích để kiểm tra kết quả trước khi tạo file.
